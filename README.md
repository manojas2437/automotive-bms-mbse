# Automotive BMS – MBSE Architecture

**Portfolio Project**

## Project Overview
Model-Based Systems Engineering (MBSE) implementation of an automotive Battery Management System (BMS) for a high-voltage electric vehicle battery pack.

## Key Engineering Areas
* SysML system architecture
* Requirements engineering
* Functional and logical decomposition
* Hardware/software allocation
* Functional safety
* Cybersecurity considerations
* Verification and validation

* **Tools:** VS Code | PlantUML | Python | Git | GitHub
